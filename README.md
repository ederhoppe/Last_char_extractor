## Descripción

Este script es una herramienta de interacción básica que solicita el nombre de una película al usuario y devuelve el último carácter de dicho texto. Es un ejercicio fundamental para comprender el manejo de índices en cadenas de texto dentro de Python.

## Conceptos Aplicados

* **Interacción Dinámica:** Uso de `input()` para capturar datos en tiempo real.
* **Indexación de Strings:** Uso del índice negativo `[-1]` para acceder directamente al último carácter de una cadena.
* **Salida Estándar:** Implementación de `print()` para mostrar el resultado en consola.

## Cómo funciona

1. El programa lanza un mensaje de bienvenida.
2. El usuario ingresa el nombre de una película.
3. El programa extrae el último carácter del texto ingresado y lo muestra en pantalla.
